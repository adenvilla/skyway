## Skyway Forwarders rebuild (multi-page)

- **Build**: static site generated by `build.py`. Page bodies live in `src/pages/*.html`, shared chrome in
  `src/shell.html`. Output is `*.html` at the project root (8 pages). After editing anything in `src/`,
  `css/` or `js/`, run `python3 build.py`.
- **Pages**: `index`, `services`, `lanes`, `calculators`, `tracking`, `network`, `about`, `contact`.
- **CSS**: `css/base.css` (tokens, progress bar, header, logo), `components.css` (hero, route arc, dock,
  footer, toast), `pages.css` (page heads, chips), `layout.css` (network, calculators, contact, map card),
  `responsive.css` (1080/900/720/420, RTL, print).
- **JS**: `js/app.js` (all interactions), `js/i18n.js` + `js/lang/{tr,ar,so,t1..t7}.js` (translations),
  `js/ui.js`, `js/data.js`. Script order matters: t1–t7 must load before `ui.js`/`app.js`.
- **Preview**: `python3 -m http.server $PORT --bind 0.0.0.0` (service `freecode-preview`, port 3000).
- **Languages**: EN / 中文 / Türkçe / العربية / Soomaali. Arabic sets `dir=rtl`. `i18n` audit script:
  `/tmp/audit_i18n.js` — must report `missing 0` for all five.
- **Contact dock** (`.rail`): seven circular buttons pinned to the left edge, vertically centred, built from
  the redirects Skyway actually publishes: WhatsApp `wa.me/254720000213`, Messenger
  `m.me/skywayforwardersltd`, phone `tel:+254720000213`, Instagram `ig.me/m/skywayforwardersltd`, WeChat

  link, TikTok `@skywayforwardersltd`. At ≤1080px it becomes a bottom bar.

  Eastleigh, opposite Pumwani Maternity Hospital main gate. Phones 0720 000 213 / 0791 888 803. Emails
  skyway@skyway.co.ke, skywaycargo22@gmail.com. Hours Mon–Sat 8:00–17:30.
